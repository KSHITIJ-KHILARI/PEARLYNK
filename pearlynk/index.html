How It Works

Three steps from URL to verdict. No sign-up. No server. No wait.

  1. 1

    Submit a URL

    Paste any link into the popup or click Analyze Current Tab to scan the page you are on.

  2. 2

    Local Heuristic Engine

    Pearlynk evaluates HTTP vs HTTPS, IP hosts, subdomain depth, length, suspicious keywords, punycode, obfuscation, lookalike domains and risky TLDs.

  3. 3

    Score & Explain

    You get a 0–100 risk score a Safe / Suspicious / High Risk verdict and a list of detected signals with their impact.

Install in 60 seconds

Load the unpacked extension in Chrome or any Chromium-based browser.

1

Download

Download or clone the Pearlynk repository to your computer.

2

Extract ZIP

If you downloaded a ZIP extract it to a folder. Chrome requires an unzipped directory.

3

Open Extensions

Go to chrome://extensions and enable Developer mode.

4

Load Unpacked

Click Load unpacked and select the Pearlynk folder. Pin the icon to your toolbar.

Frequently Asked Questions

Quick answers to common questions about Pearlynk.

Is Pearlynk free?

Yes. Pearlynk is open-source and free to use. There are no paid tiers, no subscriptions and no account required.

Does Pearlynk guarantee a site is safe?

No. Pearlynk provides heuristic signals and a risk score not a safety guarantee. Always verify links through additional trusted sources before entering sensitive information.

Why must I extract the ZIP before loading it?

Chrome requires an unzipped directory to load an unpacked extension. Loading a ZIP file directly is not supported by the browser.

Is my browsing data private?

Yes. All analysis runs locally in your browser. History is stored in Chrome’s local storage. Pearlynk never sends data to external servers.
